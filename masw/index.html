On Fredericton jobsites, the difference between Class C and Class D can push a project into a whole new structural design tier. We see it often along the Saint John River floodplain, where soft alluvial silts overlie dense lodgment till. A building that looks fine on paper suddenly needs a seismic upgrade because the site period lengthens. The MASW method cuts through that uncertainty. One survey line, a few hours of acquisition, and we map the shear wave velocity profile to 30 meters depth—the VS30 value the NBCC 2015 requires. For projects near the riverbank or up on the Devonian shale of College Hill, we combine seismic refraction to resolve bedrock depth and test pits to ground-truth the near-surface stratigraphy before finalizing the site class recommendation.

VS30 is not a single number you pull from a county map. It changes within 50 metres when you cross a buried valley or a till margin.

Technical details of the service in Fredericton

Fredericton’s glacial geology creates sharp velocity contrasts that MASW captures well. Downtown, the post-glacial marine silts can show VS30 values below 180 m/s—Class D territory—while the dense lodgment till on the UNB campus easily exceeds 360 m/s. The shale bedrock underlying the city drops off the radar: shear wave velocities jump to 800–1200 m/s, which is Class B or better. We run 24-channel active-source MASW with 4.5 Hz geophones, processing in the frequency-phase velocity domain. That gives us a dispersion curve we invert to a 1D shear wave velocity profile. For taller structures requiring deeper investigation, we extend the profile with passive-source microtremor arrays. The whole process follows ASTM D4428 for crosshole and downhole methods, adapted to surface-wave acquisition as recommended by the NEHRP guidelines for site classification. Where the soil column is thin and bedrock is shallow—like parts of Marysville—we pair MASW with CPT testing to validate the transition depth and rule out velocity inversions that surface-wave methods can miss.

Typical technical challenges in Fredericton

A 6-storey mixed-use project on Regent Street hit a wall during permit review. The geotechnical report assumed Class C based on a single borehole. The city’s peer reviewer flagged it—too close to the river, too little shear-wave data. We ran a MASW line across the site and found VS30 of 210 m/s. Class D. The structural engineer had to retrofit the lateral system. The fix cost six figures. On a site 300 metres inland, the same formation registered 390 m/s. That’s the gamble with Fredericton’s buried valleys and glaciofluvial channels. Presumptive classification works until it doesn’t. MASW gives you measured data, not a guess. For critical facilities—schools, emergency response buildings, post-disaster structures—the NBCC requires a site-specific seismic study. Our reports include the dispersion curves, inversion parameters, and VS30 calculation so the reviewer can follow every step.

Do I need a MASW survey if I already have borehole data?

Possibly. Boreholes give you blow counts and material descriptions—useful for bearing capacity and settlement—but they don't directly measure shear wave velocity unless you run downhole or crosshole tests. The NBCC allows site class estimation from SPT N-values and undrained shear strength for some soil types, but the correlation introduces uncertainty. If your site is within 100 metres of the Saint John River, mapped as soft soil, or if you're designing a post-disaster building, the code reviewer will almost certainly ask for measured VS30 data. MASW is the fastest way to get it without drilling.

How long does a MASW field test take in Fredericton and will it disrupt my site?

A typical active-source MASW line takes about two hours to set up and acquire. The geophone array is 46 metres long for a standard survey, laid out on the ground surface—no drilling, no trenching, no heavy equipment. We can run it on grass, gravel, or asphalt. The test itself involves striking a plate with a sledgehammer at multiple shot points. It's quiet enough that we can work next to occupied buildings without disruption. If we need passive-array data for deeper profiling, we leave a smaller array recording ambient noise for 30 to 60 minutes. Most residential and commercial sites are back to normal operations by noon.
